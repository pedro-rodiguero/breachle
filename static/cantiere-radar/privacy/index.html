Privacy Policy

Cantiere Radar · effective October 27, 2026

Cantiere Radar is a personal, internal tool operated by Pedro Rodiguero (Cantiere) on his own computer. It is not offered to the public, and the only Google account that signs in to it is the operator's own.

What the app accesses

With the operator's permission, the app uses the Gmail API on the operator's own Gmail account to:

  • create e-mail drafts (text and inline images) that the operator reviews and sends himself;
  • read the threads of those messages, including sender, date and a short snippet, to know when a draft was sent and whether the recipient replied;
  • read, label and send messages in that account when the operator asks his own assistant tools to do so.

How the data is used and stored

Data is used only to show the status of the operator's own outreach (sent, replied, bounced) and to remind him to answer. It is stored locally on the operator's machine. When a reply arrives, the sender and snippet are sent as a private notification to the operator's own Telegram chat. Nothing is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services

Cantiere Radar's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored data is deleted by removing the app's data folder.

Política de Privacidade

Cantiere Radar · vigente desde 27 de outubro de 2026

O Cantiere Radar é uma ferramenta pessoal e interna, operada por Pedro Rodiguero (Cantiere) no próprio computador. Não é oferecida ao público, e a única conta Google que faz login nela é a do próprio operador.

O que o app acessa

Com a permissão do operador, o app usa a Gmail API na conta Gmail do próprio operador para:

  • criar rascunhos de e-mail (texto e imagens embutidas), que o operador revisa e envia ele mesmo;
  • ler as conversas dessas mensagens, incluindo remetente, data e um trecho curto, para saber quando o rascunho foi enviado e se o destinatário respondeu;
  • ler, rotular e enviar mensagens nessa conta quando o operador pede isso às próprias ferramentas de assistência.

Como os dados são usados e guardados

Os dados servem só para mostrar a situação dos contatos do próprio operador (enviado, respondido, devolvido) e lembrá-lo de responder. Ficam guardados localmente, na máquina do operador. Quando chega uma resposta, o remetente e o trecho vão como notificação privada para o Telegram do próprio operador. Nada é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos de IA.

Serviços de API do Google

O uso e a transferência de informações recebidas das APIs do Google pelo Cantiere Radar seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar o acesso e apagar os dados

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os dados locais são apagados removendo a pasta de dados do app.
